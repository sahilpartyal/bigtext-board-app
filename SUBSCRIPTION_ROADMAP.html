3 Platform Setup

⚠️ Important
Complete platform setup BEFORE writing code. Products must exist in stores for testing.

Apple App Store Connect

Step 1: Agreements

App Store Connect → Agreements, Tax, and Banking → Accept "Paid Applications" agreement

Step 2: Create Products

Your App → In-App Purchases → Manage → Create:

  • Auto-Renewable Subscription: bigtext_pro_monthly
  • Auto-Renewable Subscription: bigtext_pro_yearly
  • Non-Consumable: bigtext_pro_lifetime

Step 3: Subscription Group

Create group "BigText Pro" and add monthly/yearly subscriptions

Step 4: Sandbox Testers

Users and Access → Sandbox Testers → Create test accounts

Google Play Console

Step 1: Merchant Account

Play Console → Setup → Payments profile → Set up merchant account

Step 2: Create Products

Your App → Monetize → Products:

  • Subscriptions: bigtext_pro_monthly, bigtext_pro_yearly
  • In-app products: bigtext_pro_lifetime

Step 3: License Testers

Setup → License testing → Add tester Gmail accounts

6 Implementation Steps

Phase 1: Core Infrastructure

  1. Add in_app_purchase dependency
  2. Configure iOS entitlements & Android permissions
  3. Create PurchaseService with init, buy, restore methods
  4. Create SubscriptionProvider with Riverpod
  5. Add product IDs to constants.dart

Phase 2: Data Layer

  1. Add isPro boolean to AppSettings model
  2. Add subscriptionType enum (free, monthly, yearly, lifetime)
  3. Add subscriptionExpiry DateTime
  4. Update SharedPreferences persistence

Phase 3: Subscription Screen

  1. Create SubscriptionScreen with plan cards
  2. Build PlanCard widget for each tier
  3. Add FeatureList comparison widget
  4. Implement RestoreButton for previous purchases
  5. Add route /subscription to app_pages.dart

Phase 4: Feature Gating

  1. Create LockedFeature overlay widget
  2. Create ProBadge indicator widget
  3. Modify ModeSelector - lock Business/Presentation
  4. Modify FontSelector - limit to 4 free fonts
  5. Modify ColorSwatchGrid - limit to 6 free colors
  6. Lock custom logo feature

Phase 5: Free Tier Restrictions

  1. Create Watermark widget
  2. Add watermark to MainDisplayScreen for free users
  3. Limit recent messages to 10 for free tier
  4. Add "Upgrade to Pro" button in settings

Phase 6: Testing

  1. Test purchase flow on iOS sandbox
  2. Test purchase flow on Android license testing
  3. Test restore purchases
  4. Test subscription expiry handling

Provider Check Pattern

// In any widget that needs Pro check: class MyWidget extends ConsumerWidget { @override Widget build(BuildContext context, WidgetRef ref) { final isPro = ref.watch(subscriptionProvider).isPro; if (!isPro) { return LockedFeature( onTap: () => Navigator.pushNamed(context, '/subscription'), child: /* locked UI */, ); } return /* unlocked UI */; } }
