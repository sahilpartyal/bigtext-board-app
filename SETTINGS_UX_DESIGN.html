UX Design Principles

Anti-Patterns to Avoid

  • Flat lists with no visual hierarchy
  • Hidden settings behind multiple taps
  • No preview of changes in real-time
  • Aggressive pro gating that frustrates users
  • Settings that don't persist across sessions
  • Unlabeled icons and confusing sliders

Best Practices Applied

  • Grouped settings in collapsible card sections
  • Visual icons for quick scanning
  • Immediate preview of all changes
  • Soft pro gating — show, don't hide
  • Persistent state via Riverpod + local storage
  • Clear labels with descriptive values
Design Philosophy Settings should feel like a creative tool, not a configuration panel. Users customize their display in real-time, seeing changes instantly. Pro features are visible but gently locked — creating desire without frustration. Cards are collapsible by default (except Display Mode) to reduce cognitive load.

Color Swatch Design

Color Swatch Styling

Design Approach

  • Rounded rectangle shape (12px border-radius)
  • Soft/pastel fill colors for the interior
  • Vibrant border color matching the hue
  • 2px border width for clear definition
  • Lock icon overlay for pro-only colors
  • Checkmark for selected state

Example Colors

Soft Fill + Vibrant Border Pattern Each color swatch uses a soft pastel version for the fill (e.g., #fecaca for red) while the border uses the vibrant/saturated color (e.g., #ef4444 for red). This creates visual harmony while maintaining color identification.
